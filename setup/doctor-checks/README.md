# Doctor checks

`src/lib/doctor.js` reports three independent sections. `PACKAGE_READY` validates the running package version, Node version, packaged skills, provider recipes, tool annotations, bundled connector startup, replay fixtures, and packaged Git exclusions. `PROJECT_CONFIGURED` validates the install manifest and fingerprints, project/CLI version alignment, documentation decision, resumable setup state, environment profiles, active host state, and the exact managed MCP entries currently on disk. `INVESTIGATION_READY` requires live data and observability initialization, an exact read-only tool allowlist, and bounded environment-identity reads.

Legacy projects retain source-registry and activated-connector checks. For every entry in `.investigator/activated-connectors.json`, doctor verifies the referenced bearer or OAuth environment variable, MCP initialization, negotiated protocol header, `tools/list`, allowlist resolution, and a harmless bounded read probe. Package-only mode validates the distributed kit without requiring project activation. `rooty --version` and `rooty -V` print the running CLI version; normal doctor output also reports the CLI and installed project versions.
